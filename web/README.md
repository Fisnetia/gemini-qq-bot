# Web 管理台

浏览器管理台（React + Vite），只调用 `/api/v1` 管理 API。

## 构建

```bash
cd web
npm install
npm run build   # 产物在 web/dist/
```

## 部署

给机器人进程设置环境变量 `WEB_DIST` 指向构建产物目录，管理监听会在
`/console/` 下托管这个目录：

```bash
WEB_DIST=/opt/gemini-qq-bot/web/dist
# 打开 http://<管理监听地址>/console/
```

静态文件本身不带鉴权（页面里没有任何数据），所有 API 调用仍需管理
令牌：打开页面后输入部署时配置的 `ADMIN_TOKEN`，令牌只保存在标签页
的 sessionStorage 里。

本地开发可用 `npm run dev`，Vite 会把 `/api` 代理到
`http://127.0.0.1:18081`。

## 页面

- **总览**：生产就绪与阻断项、额度双桶与重置时间、节奏档位、aux 当前模式与健康、发件箱积压。
- **群管理**：已发现待启用的群（选档位一键启用）、服务中/已停用/已被移出的群；每群可开关、暂停、改参与档位、重置会话、浏览与删除记忆。
- **人设卡**：编辑人设卡并保存——保存后各群在下一轮对话换上新卡（输出契约是内置的，不在这里编辑）；可一键恢复内置默认卡。
- **表情**：表情库浏览，按收编状态筛选，收编/忽略/启停/删除。
- **设置**：aux 网关（地址/模型/粘性会话头/密钥只写不回读）与连通性测试；停用网关即自动落 agy 模式，界面有明示。运行开关：主会话自动轮换、按额度降级，均带代价说明。所有设置热生效并持久化（服务端 `runtime-settings.json` 覆盖层）。
